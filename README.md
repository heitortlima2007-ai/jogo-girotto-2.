# jogo-girotto-2.
jogo criado como trabalho da faculdade
Este jogo é um Dungeon Crawler em C baseado em turnos e com gráficos em texto (ASCII Art).
A Vila: O jogador fala com o NPC (N) para escolher uma arma: Espada (curto alcance/área), Arco (longo alcance em linha reta) ou Cajado (área circular $3 \times 3$).Andar 1 ($10 \times 10$): Tutorial. Colete a chave (@), abra a porta (D), destrua a caixa (k) e use a escada (L).Andar 2 ($15 \times 15$): Pegue 2 chaves, abra 2 portas e desvie dos espinhos (#) e do Monstro X (movimento aleatório). Use o botão (O) para remover espinhos.Andar 3 ($25 \times 25$): Enfrente o Monstro X, o Monstro Y (persegue o jogador) e o Boss Z (3 vidas, movimento misto). 
Derrote o Boss para liberar a escada da vitória.Vidas e Reset: O jogador tem 3 vidas. Tocar em monstros ou espinhos tira 1 vida e reinicia o andar atual.

Game Over: Com 0 vidas, o jogo limpa o progresso e volta para o menu principal.

Ataque: O personagem muda de ícone conforme anda (^, v, <, >), definindo para onde desferirá os golpes.
